========
pyregion
========

:Release: |version|
:Date: |today|


.. note::

    The ``regions`` package
    at https://github.com/astropy/regions
    supercedes pyregion.
    The pyregion package is deprecated and unmaintained.

pyregion is a python module to parse ds9 region files.
It also supports ciao region files.
